# 🤖 KIR4LR — WhatsApp Multi-Device Bot

**Created & Customized by Larskibidi**

Bot WhatsApp Multi-Device modern dengan sistem plugin modular, **Semi-Button Interactive Menu** (`single_select` + `quick_reply`), Pairing Code custom (`KIR4LRMD`), dan fitur siap pakai tanpa API key berbayar.

## ✨ Fitur Utama
- 📋 **Semi-Button Menu** (`.menu`, `.menu all`, `.menu <kategori>`)
- 📥 **TikTok Downloader No-WM + Audio MP3 + Slide Foto** (`.tiktok`, `.tt`, `.ttmp3`)
- 🖼️ **Sticker Maker & Sticker to Image** (`.sticker` / `.s`, `.toimg`)
- 🛡️ **Manajemen Grup Lengkap**: `.antilink on/off`, `.welcome on/off`, `.goodbye on/off`, `.hidetag`, `.kick`, `.promote`, `.demote`
- 👑 **Owner Tools**: `.broadcast`, `.setmode`, `.self`, `.schedule`, `.listowner`, `.listprem`
- ⚡ **Info & Utilitas**: `.ping`, `.runtime`, `.infobot`, `.owner`, `.profile`, `.dice`, `.flip`
